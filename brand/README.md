# Cotsi brand files

The logo is the **Rising C**: a C made of five segments, one for each learning method Cotsi
teaches with (the vital 20% first, a question after every idea, explaining it back, scenes that
fix misconceptions, spaced reviews). The segments brighten as they rise, and the opening ends in
the Thapa diamond: the job you're aiming for.

Colours: purple `#7c6af7` to pink `#d08cff` on near-black `#0a0910`. Wordmark font: Thapa.

Regenerate the SVGs with `python3 brand/make_logo.py`.

| File | Use it for |
|---|---|
| `cotsi-logo-square-500.png` | Peerlist logo and any site that rounds or crops the image itself |
| `cotsi-logo-square-1024.png` | LinkedIn, Instagram, YouTube, X profile pictures |
| `cotsi-logo-500.png`, `cotsi-logo-1024.png` | Rounded app-icon tile with transparent corners (slides, docs) |
| `cotsi-mark-1024.png`, `cotsi-mark.svg` | The C alone, transparent, for dark backgrounds |
| `cotsi-mark-light-1024.png`, `cotsi-mark-light.svg` | The C alone, transparent, for light backgrounds |
| `cover-1-hero.png` … `cover-4-learn.png` | Peerlist cover images and link previews (1200×630) |
| `favicon.ico`, `favicon-16/32/48.png`, `cotsi-logo.svg` | Browser tab icons |
| `apple-touch-icon-180.png`, `icon-192.png`, `icon-512.png` | Phone home-screen icons |

`logo-concepts/` keeps the six first drafts for reference.
